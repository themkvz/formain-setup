# Plan 002: Prune stale links and generated agents; fail loud on bad frontmatter

- **Priority**: P1 | **Risk**: MED (deletes files in `$HOME`) | **Depends on**: 001

## Problem

1. `bootstrap.sh`, `sync-codex-agents.sh`, and `sync-gemini-agents.sh` only process sources that exist today. When a skill or agent is renamed or deleted, its old symlinks stay dangling and its generated Gemini/Codex agent files remain active with outdated instructions. `doctor.sh` does not report them.
2. `sync-codex-agents.sh` reads one plain `description:` line and wraps the body in `'''...'''`. Quoted/multi-line YAML descriptions or `'''` in the body silently produce wrong or invalid TOML.

## Files

- `bootstrap.sh`
- `scripts/sync-codex-agents.sh`
- `scripts/sync-gemini-agents.sh`
- `scripts/doctor.sh`
- `scripts/test.sh`
- `README.md`

## Changes

### 1. `bootstrap.sh` — prune dangling links pointing into `$AI_HOME`

Add after `link_dir`:

```bash
prune_dangling() {
  local dir="$1"
  local link

  [[ -d "$dir" ]] || return 0

  for link in "$dir"/*; do
    [[ -L "$link" && ! -e "$link" ]] || continue
    [[ "$(readlink "$link")" == "$AI_HOME"/* ]] || continue

    run rm "$link"
    echo "Pruned: $link"
  done
}
```

Call it:
- After the skills loop for all 4 skill dirs: `~/.claude/skills`, `~/.gemini/config/skills`, `~/.agents/skills`, `~/.agent/skills`.
- After the agents loop for `~/.claude/agents`.

### 2. `scripts/sync-codex-agents.sh` — mark, prune, and guard frontmatter

1. Define `MARKER="# Generated by ~/.ai/scripts/sync-codex-agents.sh. Do not edit."` and emit it as line 1 of each generated `.toml`.
2. In `sync_agent`, right after reading `description` (before escaping):

```bash
  case "$description" in
    ''|\"*|\'*|'>'*|'|'*)
      echo "Unsupported description in $source: use one plain unquoted line" >&2
      exit 1
      ;;
  esac
```

   And right after reading `body`:

```bash
  if [[ "$body" == *"'''"* ]]; then
    echo "Agent body contains ''' and cannot be written as TOML: $source" >&2
    exit 1
  fi
```

3. After the sync loop, prune orphans whose first line matches `$MARKER`:

```bash
for target in "$DST"/*.toml; do
  [[ -f "$target" && ! -L "$target" ]] || continue
  [[ "$(head -n 1 "$target")" == "$MARKER" ]] || continue
  [[ ! -f "$SRC/$(basename "$target" .toml).md" ]] || continue

  rm "$target"
  echo "Pruned: $target"
done
```

### 3. `scripts/sync-gemini-agents.sh` — mark and prune generated agents

1. Define `MARKER="<!-- Generated by ~/.ai/scripts/sync-gemini-agents.sh. Do not edit. -->"` and append it as the last line of each generated `.md` (`printf '%s\n' "$MARKER" >> "$target"`), leaving YAML frontmatter at line 1 untouched.
2. After the sync loop, prune orphans whose last line matches `$MARKER`:

```bash
for target in "$DST"/*.md; do
  [[ -f "$target" && ! -L "$target" ]] || continue
  [[ "$(tail -n 1 "$target")" == "$MARKER" ]] || continue
  [[ ! -f "$SRC/$(basename "$target")" ]] || continue

  rm "$target"
  echo "Pruned: $target"
done
```

### 4. `scripts/doctor.sh` — report dangling links and orphan generated agents

1. Add `check_dangling` (same checks as `prune_dangling`, calling `fail "Dangling link: $link (run bootstrap.sh)"`).
2. Call `check_dangling` after the skills loop (4 skill dirs) and after the agents loop (`~/.claude/agents`).
3. After the agents loop, `fail` on any regular non-symlink:
   - `~/.gemini/config/agents/*.md` whose last line matches the Gemini marker and whose `$AI_HOME/agents/<name>` is missing.
   - `~/.codex/agents/*.toml` whose first line matches the Codex marker and whose `$AI_HOME/agents/<name>.md` is missing.

### 5. `scripts/test.sh` — add regression checks

Insert before `==> Doctor reports no failures`. Always target `$TEST_HOME` and invoke scripts with `env HOME="$TEST_HOME"`:

- Create a dangling skill link (`$TEST_HOME/.claude/skills/x-gone`), a dangling Claude agent link (`$TEST_HOME/.claude/agents/gone.md`), a foreign dangling link (`$TEST_HOME/.claude/skills/foreign` → `$TEST_HOME/elsewhere`), marked orphan Gemini/Codex files (`gone.md`, `gone.toml`), and unmarked foreign Gemini/Codex files (`mine.md`, `mine.toml`).
- Run `env HOME="$TEST_HOME" "$TEST_HOME/.ai/bootstrap.sh" >/dev/null`.
- Assert all 4 owned leftovers are gone and all 3 foreign files remain.

### 6. `README.md`

Add one bullet under "What bootstrap does with files that already exist" explaining that dangling `~/.ai` links and marked generated agent files without a source are pruned, while foreign files are left alone.

## Safety rules

- Never delete anything that is not either a dangling symlink pointing into `$AI_HOME/` or a non-symlink generated file carrying the marker.
- Keep macOS Bash 3.2 compatibility (no associative arrays, no `mapfile`).
- Pre-existing generated files without markers gain them on the next sync; pre-existing orphans must be removed manually once.
